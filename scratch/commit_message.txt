- User Store & Coin Page: เพิ่มหน้า `/shop/coins` รองรับการเติมเงิน Coin (Preset 50-1000฿ หรือระบุยอดเอง) พร้อมคำนวณโบนัสและตัวคูณอัตโนมัติ

- Checkout Integration: เพิ่ม API `POST /api/checkout/coins/purchase` รองรับการชำระเงินค่าสินค้าด้วย Coin สะสมของผู้เล่น
